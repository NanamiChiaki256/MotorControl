# MotorControl

基于 **STM32F103C8T6 + FreeRTOS + TB6612FNG + 编码器电机 + INA226 + OLED** 的嵌入式学习工程，使用 STM32CubeMX、Keil MDK 和 STM32 HAL。

截至 **2026-10-26**，本阶段按“单方向、空载速度闭环演示”的范围完成实机验收：目标速度约 1000 计数/秒，串口启停，OLED 显示，电压/电流监测，以及软件故障停机和锁定。

**这是空载实验演示，不是经过带载、真实过流或短路验证的安全控制器。** 当前 20mA 是本工况的实验性报警阈值，不是电机额定保护参数。

## 已实现功能

- FreeRTOS 的 defaultTask、CounterTask，以及任务计数队列和串口接收队列。
- USART1 中断接收命令，任务内处理命令，运行期间不使用长延时等待停止。
- TIM3 CH1 输出约 20kHz PWM，TB6612FNG A 通道驱动电机。
- TIM2 TI1/TI2 编码器模式读取 A/B 信号，约每 100ms 按实际时间间隔计算速度，并处理 16 位计数回绕。
- PI 速度控制、输出限幅、积分限幅和条件积分；未使用 D 项。
- OLED 硬件 I2C 显示累计计数、运行状态、最近串口字符、电流和速度。
- INA226 软件 I2C 地址检测、身份寄存器读取、启动时总线电压测量和运行时电流测量。
- `S` 提前停止、约 5 秒自动停止、持续无反馈停机、电流超限停机、运行时 INA226 读取失败停机。
- 故障锁定：故障后 `R` 不重启，`S` 清除故障但不自动启动。

## 硬件连接

### 信号连接

| STM32 引脚 | 连接对象 | 用途 |
|---|---|---|
| PA0 | 编码器 A | TIM2 CH1 |
| PA1 | 编码器 B | TIM2 CH2 |
| PA6 | TB6612 PWMA | TIM3 CH1 PWM |
| PB0 | TB6612 AIN1 | A 通道方向 |
| PB1 | TB6612 AIN2 | A 通道方向 |
| PB10 | TB6612 STBY | 驱动使能 |
| PB12 | INA226 SCL | 开漏 GPIO 软件 I2C 时钟 |
| PB13 | INA226 SDA | 开漏 GPIO 软件 I2C 数据 |
| PB8 | OLED SCL | 重映射 I2C1_SCL |
| PB9 | OLED SDA | 重映射 I2C1_SDA |
| PA9 | USB-TTL RX | USART1 TX，3.3V 逻辑 |
| PA10 | USB-TTL TX | USART1 RX，3.3V 逻辑 |
| PA13 | ST-Link SWDIO | SWD 下载/调试 |
| PA14 | ST-Link SWCLK | SWD 下载/调试 |
| GND | 电源负极、驱动、传感器、串口和调试器地 | 公共参考地 |

OLED 七位地址为 `0x3C`；HAL 接口使用左移后的 `0x78`。本次 INA226 七位地址为 `0x40`，身份读数为 `MFR=0x5449`、`DIE=0x2260`。

### 供电与电流测量路径

```text
电机电源正极（标称6V） → INA226 VIN → 板上R010电阻 → VOUT → TB6612 VM
电机电源负极          → TB6612 GND，并与STM32及INA226共地
逻辑3.3V电源轨        → TB6612 VCC、INA226 VCC、编码器VCC、OLED VCC
TB6612 AO1/AO2        → 电机两根动力线
```

- INA226 的 `VOUT` 是经过分流电阻的供电路径，不是稳压输出；禁止保留直接从电源正极到 VM 的旁路。
- 不要将 6V 接到 MCU、INA226 或驱动板的逻辑 VCC；逻辑供电和电机 VM 供电用途不同。
- 电机电流回路直接回电源负极，不依赖 MCU 或面包板的细地线承载完整电机电流。
- INA226 的两个蓝色 GND 端子和逻辑 GND 为同一公共地，按实际板子确认后共地即可，不必每个孔都接线。ALER 引脚目前不使用。
- 本次使用 ST-Link 给逻辑部分供电；不要未经检查就并接另一份逻辑电源，也不要让已断电的调试器被外部电源反向供电。

本次六芯线束对应：红/粉色接 AO1，白色接 AO2，黑色为编码器 VCC，橙色为编码器 GND，黄色接 PA0，绿色接 PA1。**颜色仅适用于本次核对过的线束，不能当作其他电机的通用标准，尤其黑线在这里不是地。**

## 当前参数与测量含义

| 项目 | 当前值/方式 |
|---|---|
| 系统时钟 | HSI 8MHz，无 PLL |
| HAL 毫秒时基 | TIM1；`HAL_GetTick()` 在本工程中不是由 SysTick 更新 |
| FreeRTOS 时基 | SysTick，1000Hz |
| UART | USART1，115200，8N1，无流控 |
| PWM | TIM3，PSC=0，ARR=399，约 20kHz |
| 启动比较值 | 80，即 20% |
| PI 基础比较值 | 60，即 15% |
| PWM 输出限制 | 比较值 0～80，即 0%～20% |
| 目标速度 | `targetCps = 1000`，单位为计数/秒 |
| PI 参数 | `kp = 0.02f`、`ki = 0.05f` |
| 积分补偿范围 | -20～+20 个 PWM 比较值计数；输出饱和且误差继续向外推动时暂停积分 |
| 测速/电流读取 | 同一任务中约每 100ms 执行，非严格硬实时周期 |
| 自动停止 | 每次 R 启动后约 5000ms |
| 无反馈检测 | 运行期间连续约 500ms 未检测到 CNT 变化 |
| 电流报警 | 启动前 300ms 不判断超限；之后连续 3 次采样达到或超过 20mA 则停机 |
| 读取失败模拟 | `INA_READ_FAIL_TEST = 0U`，最终验收版本已关闭 |

速度计算使用 `计数增量 × 1000 / 实际间隔毫秒数`，16 位回绕修正要求采样之间的计数增减绝对值小于 32768。`ENC` 是最近读取的 TIM2 CNT 快照；`V:` 是计数/秒，不是 RPM。每圈有效计数尚未标定，不能直接换算输出轴转/分。

INA226 板上 `R010 = 0.01Ω`。程序读取 `0x01` 的有符号分流电压，按每计数 2.5µV 换算：

```text
电流(mA) = 有符号原始计数 × 2.5µV / 0.01Ω = 有符号原始计数 / 4
```

最终使用整数毫安显示，小数被截去；测量分辨率不等于精度。`0x02` 总线电压按每计数 1.25mV 换算。本工程未配置 INA226 内部电流/功率校准寄存器，而是在 STM32 中计算电流。

**当前测的是驱动板 VM 供电支路电流，不是 PWM 驱动下的绕组电流，也不是整套系统全部供电电流。**

## 操作与故障状态

| 串口命令 | 行为 |
|---|---|
| `R` / `r` | 无故障且已停止时启动单方向 PI 控制；运行中重复 R 不延长 5 秒计时 |
| `S` / `s` | 关闭驱动和 PWM，清空积分并清除故障；不会自行重启 |

| 故障宏 | OLED 提示 | 处理 |
|---|---|---|
| `MOTOR_FAULT_NO_ENCODER` | `FAULT: NO ENC` | 无反馈停机并锁定 |
| `MOTOR_FAULT_OVERCURRENT` | `FAULT: CURRENT` | 连续电流超限停机并锁定 |
| `MOTOR_FAULT_INA_READ` | `FAULT: INA I2C` | 运行期间 INA226 读取失败，停机并锁定 |

每次故障先排查原因；修复后发送 S 清除，再明确发送 R 才重新运行。停止状态下 INA226 读取失败会显示 ERR，但不会锁定运行故障；若此时启动，后续读取仍失败会触发停机。

OLED 第一行显示编码器累计计数，第二行显示 STOP、运行 PWM 或故障，第三行显示最近字符和电流，第四行保留任务计数及 `V:` 速度。PWM 显示为整数百分比，实际比较值调节更细。

## 编译、下载与运行

开发环境记录：STM32CubeMX 6.17.0、STM32CubeF1 V1.8.7、Keil µVision 5.24.2.0、Arm Compiler 5.06 update 5、Keil.STM32F1xx_DFP 2.2.0、CMSIS-RTOS v1 封装的 FreeRTOS。更换工具或硬件时需要重新验证兼容性。

1. 克隆仓库，用 Keil 打开 `MDK-ARM/MotorControl.uvprojx`，安装器件包并选择兼容编译器。
2. 断开电机 6V，检查接线和供电，再接通 ST-Link 逻辑供电。
3. 编译。最后一次可读到的本机编译日志为 **0 Errors、0 Warnings**。
4. 配置 SWD 并下载。当前四线接法没有 NRST，使用 `Port=SW`、`Connect=Normal`、`Reset=Autodetect`，请求下载时钟 1MHz；调试器实际选择值以界面为准。
5. 退出调试，让程序运行。启动阶段检测 INA226、显示身份/总线电压并停留约 3 秒，随后进入正常任务界面。等待 `MOTOR: STOP` 后才操作电机供电。
6. 固定电机外壳，转轴空载，线和塑料袋远离齿轮；接通 6V 后发送 R。观察速度和电流，确认约 5 秒停止。
7. 如需提前停止，发送 S。异常且无响应时切断 6V，不用手阻挡转轴。

实际配置源为 `MotorControl.ioc`。CubeMX 再生成前先保存或提交代码，并检查用户区域、Keil 源文件列表及自定义串口队列是否保留。不要把重新生成后“能编译”直接当作已完成实机验收。

### Keil 下载闪退记录

2026-10-26 的两次 Windows 崩溃记录指向 `ST-LINKIII-KEIL_SWO.dll` V3.0.1.0，异常码为 `0xc0000005`，当时工程已编译成功。检查发现原设置为 SWD 4MHz、Connect under Reset，而实际仅接四根线、没有 NRST。按上面的 Normal / 1MHz 设置调整后，用户报告下载成功。

这只是成功排查记录，**不能证明插件内部崩溃的具体根因或保证不再复发**。复发时应保留错误记录，检查 Keil 配套的 ST-Link 插件和连接，不应直接归因于 PI 计算或盲目替换 DLL/升级下载器固件。

## 实机验收记录与边界

下表来自用户逐步进行的实机反馈；此次文档整理未重新编译、烧写或自动执行硬件测试。

| 项目 | 验证方法与结果 |
|---|---|
| 基础显示、串口、任务/队列 | OLED、UART 收发与任务计数通过 |
| PWM 与编码器 | PWM 波形、模拟 A/B 计数及真实电机转动/测速通过 |
| 空载 PI | 速度在目标约 1000 计数/秒附近小幅变化，PWM 约 16%，电流为几毫安 |
| 正常停止 | 约 5 秒自动停止、S 提前停止通过；停稳后速度回零 |
| 电压 | INA226 约 6322mV，与万用表约 6.32V 接近 |
| 电流单点对照 | 万用表约 4.8mA，OLED 约 4～5mA；不是全量程精度校准 |
| 无反馈停机 | 保持逻辑供电、断开 6V，使电机不运动；故障停机、R 锁定、S 清除通过；正常运行不误触发 |
| 电流超限逻辑 | 使用临时 3mA 低阈值，以正常空载电流触发；停机、R 锁定、S 清除通过；之后恢复为 20mA |
| INA226 失败处理 | 软件在启动约 200ms 后模拟失败返回，停机、R 锁定、S 清除通过；最终已关闭模拟 |
| 最终正常运行 | 关闭模拟并采用 20mA 阈值后，空载运行、无误报警、5 秒停止和 S 提前停止通过 |

尚未验证或不在本阶段验收范围：

- 真实过流/短路下 20mA 阈值的保护有效性、瞬时绕组电流、带载与堵转；不得用手堵转做故障测试。
- 真实断线或 SCL/SDA 故障时底层通信超时的完整硬件故障注入测试；软件失败模拟只验证上层处理路径。
- 全量程电流精度、温漂、长期运行、不同电源/电机、每圈计数和 RPM 标定。
- 反转、D 项、斜坡启动、通信心跳超时停机和持久化故障记录。固定 5 秒停止不等于通信中断保护。

保护和停止均依赖任务继续执行，启动电流检查还存在宽限和连续采样确认延迟，不能代替硬件限流、保险或快速短路保护。空载验收通过不代表工业安全认证。
